# 逆仙录·天道残卷

> **天道有缺，万物皆可逆。**

一个追求真实感的修仙模拟游戏，融合《凡人修仙传》《仙逆》《斗破苍穹》经典设定，参考《觅长生》《太吾画卷》《鬼谷八荒》《了不起的修仙模拟器》等游戏。

## 核心理念

**修仙不是游戏，是"活着"。** 在一个会记住你、会报复你、也会遗忘你的世界里，用有限的时间、残缺的功法、脆弱的肉身，去争那一线天机。

## 快速开始

```bash
# 安装依赖
pip install flask flask-cors

# 启动服务器
python3 server.py
```

浏览器访问: http://localhost:5000

默认管理员账号: `admin` / `admin123`

## 核心系统

### 1. 真实身体系统
- **经脉系统**：12正经+8奇经共20条经脉，受损会影响灵气运转
- **丹田**：容量、品质(impure/refined/pure/flawless)、裂纹(过多会爆体)
- **肉身强度**：皮肤、肌肉、骨骼、五脏(对应五行)
- **神识**：扫描范围、洞察力、抗夺舍能力
- **状态**：不是buff/debuff，是真实身体变化(经脉损伤、火毒、旧伤)

### 2. 真实修炼系统
- 需选择修炼地点(灵脉品质影响速度)
- 需选择周天数(效率与风险并存)
- 可服用辅助丹药、布设阵法
- 走火入魔风险(经脉负担过重)
- 突破瓶颈：水磨工夫/破境丹/生死战/顿悟
- 业力深重者突破时心魔入侵

### 3. 策略战斗系统
- 战前情报：神识扫描、地形选择
- 部位瞄准：躯体(1.0x)/头部(1.5x,眩晕)/丹田(1.3x,断灵)/肢体(0.8x)
- 灵气分配：决定攻击力度与防御保留
- 属性克制：火克冰、金克木等
- 战后真实后果：永久经脉损伤、灵气枯竭需静养

### 4. 因果/业力系统
- 因果账本记录每个行为
- 业力影响突破(心魔)、运气、天劫强度
- 因果不是即时的，会"发酵"(30-365天后触发)
- 心魔考验：突破时回忆亏心事

### 5. 多维社交系统
- 五维关系：信任/尊重/感情/利益/畏惧
- 关系是事件堆出来的，不是刷好感度
- 关系会变质：兄弟可反目，仇人可结盟
- 道侣系统：大道同行，可双修、可背叛

### 6. 真实经济系统
- 灵石分级：下品/中品(1:100)/上品(1:10000)/极品(有价无市)
- 灵石既是货币也是修炼资源
- 市场价格波动(±10%随机)
- 以物易物(高阶修士间用人情/承诺)

### 7. 寿命/时间系统
- 年龄阶段：青年(+20%修炼)/壮年/衰朽(-30%)/暮年(走火风险+200%)
- 延寿手段：延寿丹/血祭/夺舍/时间阵(各有代价)
- 闭关10年出关后世界已变

### 8. 炼丹/炼器系统
- 温度控制小游戏(觅长生风格)
- 6级品质：废丹→下品→中品→上品→极品→完美
- 丹田品质影响炼丹成功率

### 9. 种田/家园系统
- 4块农田种植灵药
- 不同种子生长周期不同(5-30日)
- 成熟后可收获

### 10. 宠物/道侣/同伴系统
- 契约符驯服妖兽
- 灵兽有忠诚度，随时间成长
- 同伴可组队探索

### 11. 宗门系统
- 10个宗门(正道/魔道/中立)
- 加入/创建/管理/转交
- 宗门福利：灵气加成、功法传授

## 技术栈

- **后端**：Python 3 + Flask + SQLite
- **前端**：HTML5 Canvas + Vanilla JS
- **数据**：JSON配置驱动，可程序化生成
- **存档**：SQLite持久化，支持多用户多存档
